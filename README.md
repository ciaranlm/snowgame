# Snowy Hamster Hangout

A Babylon.js + TypeScript cozy browser prototype with hamster avatars, sledding, snowboarding, snowball throwing, and a winter resort sandbox. 

## Run locally
```bash
cd client
npm install
npm run dev
```

## Build for production
```bash
cd client
npm run build
```

## Replace hamster model with rigged `.glb`
See `client/public/assets/README.md` for full mapping and integration guidance.
